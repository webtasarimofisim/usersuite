# Master Suite - Client (User Suite Ghost Engine)

Bu yazılım, Master Suite mimarisinin müşteri (kullanıcı) bilgisayarlarında çalışan yapay zeka entegrasyon aracıdır.
Sistem, çalıştırıldığı cihazda yapay zeka sohbetlerini (pre_inference hook) izler, lisans durumunu doğrular ve ana merkezden gelen (şifreli) Master Suite kurallarını uygular.

## Kurulum ve Kullanım
1. Bu depo içerisindeki `hooks.json` dosyasını ve `scripts/` klasörünü bilgisayarınızdaki yapay zeka eklenti dizinine kopyalayın.
2. Yapay zeka sohbet ekranında 30 günlük ücretsiz denemeyi başlatmak için:
   `/suite baslat`
3. Veya satın aldığınız PRO lisansı aktifleştirmek için:
   `/lisans KODUNUZ`
4. Lisans paneline erişmek için her zaman `/lisans` komutunu kullanabilirsiniz.
